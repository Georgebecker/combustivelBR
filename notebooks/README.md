# notebooks

Rascunho é aqui; produto é o pacote.

Notebook serve para explorar e aprender (gráfico rápido, conferência de uma hipótese, comparação de
recortes). Assim que um cálculo vira rotina ou entra na entrega, ele sai daqui e vira função testada em
`src/combustivelbr/` com teste em `tests/` — Regras de Ouro, R23.

Nada de notebook lendo dado bruto por caminho relativo quebrado: use `combustivelbr.config` para achar
`data/raw/` e `data/processed/`.
